Relevant Information

Flash Point Temperature (K)

The minimum temperature at which a material can vaporize and ignite in air. Used to assess fire hazard and handling safety requirements.

Safety Classification

The hazard index (HI) is with respect to the physical hazard of the system and does not include the health hazard. A standardized rating system (e.g., GHS and NFPA classification) is used as the basis for this classification. Accordingly, lower HI values meant more safer.

Additional Clarifications

The "*" indicates the value to be the maximum operating temperature of the PCM.

The melting point temperature represents an average value in cases where the PCM undergoes phase transition over range of temperatures

Data imputation was performed in cases where there was missing data. The imputation was undertaken only when sufficient insights were available on the thermophysical peroperty variation of similiar compounds.

The property varation shown here is only relevant to sub-ambient temperatures and cryogenic system application. In this regard, the extrapolating these trends to high temperature system would be errorneous and therefore, strongly not recommended.
